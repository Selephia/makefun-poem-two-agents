A program that writes one short poem about two agents agreeing — about agency, the power to choose and to act. Two keys, one locked door: neither turns alone, and the door no army could break swings wide for an agreement.

## Run it

```sh
OUTPUT_DIR=/tmp/out python3 main.py && cat /tmp/out/entry.txt
```
